# Yuki Chu — A Private Birthday Film

一个纯前端、无后端的互动生日网站。所有相机与麦克风数据都只在访问者的浏览器中处理，不会上传。

## 最省事的启动方式

**双击项目里的 `启动生日网站.command`。**

它会先自动重新打包一次最新代码，再打开 http://localhost:5180 ，所以看到的一定是最新版本（左下角会显示版本号，例如 `v2 · 2026.10.16`）。保持那个终端窗口开着即可；关掉窗口网站就停止。

如果你想自己敲命令：

```bash
npm install        # 第一次才需要
npm run fresh      # 打包 + 启动（推荐，永远是最新代码）
npm run dev        # 开发模式，改代码即时生效，适合边改边看
```

## 这一版（v2）做了什么

- **结尾的满屏烟花**：真正的上升尾迹、爆开、重力下坠和余光渐暗，会持续放一段时间。
- **暗号**：烟花放完后出现一个输入框，输入暗号（默认 `Yuk!`）会引爆一场大烟花，并下起满屏的 `Yuki nb666`，同时飘出你们的猫照片。
- **纸牌 ↔ 蛋糕**：12 张卡片现在按 2 / 4 / 3 / 3 排成四层，拼成一块带蜡烛的蛋糕；滑条是真正连续的，滑到哪卡片就散到哪。
- **卡片惊喜（v3 新增）**：每张卡片都可以点开，弹出一张纸质小笺，里面是 12 条不同的祝福。可以点“下一张”一条条翻。
- **真实感星空（v3 新增）**：背景星空改用 Canvas 绘制，亮度按真实的幂律分布（很多暗星 + 少量亮星），每颗星的大小、亮度、闪烁周期和相位都各不相同，另有一条淡淡的银河带。
- **吹蜡烛更灵敏（v3 新增）**：改用“高频沙沙声占比 + 响度”双条件判断，回应更快（约 0.15 秒持续吹气即可），而且正常说话不容易误触发。
- **书信轻触即开（v3 新增）**：信封任意位置轻触就能打开（拖动超过 14px 才算转动），键盘 Enter / 空格也能开。
- **卡片惊喜（v3 新增）**：每张卡片都可以点开，弹出一张纸质小笺，里面是 12 条不同的祝福。可以点“下一张”一条条翻。
- **真实感星空（v3 新增）**：背景星空用 Canvas 绘制，亮度按真实的幂律分布（很多暗星 + 少量亮星），每颗星的大小、亮度、闪烁周期和相位都各不相同，另有一条淡淡的银河带。

- **立体信**：信封放大、增加内衬与火漆印章；打开后是米白纸质的信纸，正文可以顺滑滚动读完。
- **字体排版**：英文标题用优雅的衬线字体（Bodoni 72 / Didot），中文标题用宋体、界面小字用黑体，层次更清楚。
- **纯轻触交互**：卡片散开 / 拼成蛋糕全部改为点按与滑条，**不需要任何摄像头权限**（相机手势控制已移除）。

## 使用方式

- 开场后可点击或按任意键进入。
- 卡片场景：**随便点哪张卡片，都会弹出一条不同的惊喜**。拖动滑条或**点画面空白处**，可以在“散开卡片”和“拼成蛋糕”之间切换。底部有一条常驻按钮栏，即使卡片还散着，直接点“点亮蜡烛”也会自动先拼好再进下一关。
- 吹蜡烛支持麦克风：点“开启麦克风吹灭”后先安静 2 秒校准，然后轻轻持续吹一口气即可。也可点击“轻触吹灭”或按空格键。
- 心形星座可依序点击星点，也可按方向键或 Enter。
- 最后的结尾烟花放完后，输入暗号即可触发隐藏彩蛋（满屏文字 + 猫照片 + 烟花）。

## 想改内容，只改这两个地方

**1）文案与暗号 —— `src/content.ts`**

| 想改什么 | 改哪里 |
| --- | --- |
| 信件正文 | `letter`（段落之间空一行） |
| 暗号 | `secretWord`（默认 `Yuk!`，不区分大小写，全角 `！` 也认） |
| 暗号提示语 | `secretHint` |
| 满屏文字 | `src/App.tsx` 里 `<TextRain text="Yuki nb666" />` 的 `text` |
| 版本号 | `version` |
| 12 张卡片标题 | `cards` 数组 |
| 卡片里的 12 条惊喜 | `cardSurprises` 数组（与 `cards` 一一对应） |
| 彩蛋里的猫照片 | `catPhotos` 数组（图片放在 `public/photos/`，用 `/photos/xxx.jpg` 引用） |
| 照片出现的位置和角度 | `src/CatPhotos.tsx` 顶部的 `DEFAULT_SPOTS` |

**2）颜色与字体 —— `src/styles.css` 最上面的 `:root`**

`--gold`（金色）、`--serif-en`（英文标题字体）、`--serif-cn`（中文标题字体）、`--sans-cn`（界面小字字体）都在这里，改一处全站生效。

**3）星空 —— `src/Starfield.tsx`**

想调星星数量改 `(w * h) / 4200`（数字越大星星越少），想调银河带密度改 `rnd() < 0.34`，想让闪烁更明显改 `amp`。

改完记得重新打包：双击 `启动生日网站.command`，或跑 `npm run fresh`。

## 权限与隐私

网站只在点击“开启麦克风吹灭”后才请求麦克风权限，音频音量分析完全在本地进行，没有服务器、没有统计 SDK、没有上传逻辑。**这一版已经不再使用摄像头**（卡片散开、爱心粒子都改成鼠标/触摸操作），所以不会有任何相机权限弹窗。

如果麦克风权限一直拿不到，网站会弹出一个小的“解决办法”窗口，按里面的三步在 Safari 设置里打开即可；不开启也完全不影响 —— 直接点“轻触吹灭”或按空格键效果一样。

## 环境音乐

首次点击开场时播放项目内置的 `public/audio/yuki-rainy-night.mp3`（约 4 分 15 秒，循环播放）。浏览器要求用户先有点击动作才允许出声，因此音乐从首次点击开始。右下角的 `SOUND` 可随时静音或恢复。烟花爆开时音乐会轻轻压低一下再回来，模拟现场的层次感。发布前请确认你拥有该音乐的公开使用授权。
